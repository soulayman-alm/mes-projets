## Organisation du dépôt

Chaque dossier représente une matière ou un domaine. Chaque projet contient idéalement :

- un fichier `README.md` présentant le contexte et les objectifs ;
- les rapports ou documents PDF ;
- les captures d'écran ;
- le code ou un lien vers son dépôt ;
- une démonstration lorsque celle-ci est disponible.
